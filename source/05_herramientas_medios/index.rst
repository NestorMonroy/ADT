Tablas de Equivalencias
------------------------

**[OK] LaTeX -> RST**

Tabla completa de equivalencias para traducir documentación LaTeX a reStructuredText.

Ver: :doc:`equivalencias/latex_rst_equivalencias`

**Incluye:**
- Estructura del documento (secciones, listas, tablas)
- Formato de texto (negrita, cursiva, código)
- Referencias y enlaces
- Figuras e imágenes
- Matemáticas
- Bloques especiales
- Proceso de traducción sistemática
- Herramientas de conversión
- Errores comunes

----

Uso de esta Sección
===================

**Para Traducción LaTeX:**

.. code-block:: text

 1. Abre: equivalencias/latex_rst_equivalencias
 2. Mantén abierta durante traducción
 3. Busca construcción LaTeX específica
 4. Aplica equivalente RST
 5. Compila para verificar
