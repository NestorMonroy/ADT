
Framework Diátaxis
==================

.. note::
   Diátaxis es un framework sistemático para documentación técnica que organiza
   el contenido en cuatro categorías: Tutoriales, Guías, Explicaciones y Referencia.

Introducción
============

El framework Diátaxis proporciona una estructura clara para organizar documentación
técnica de forma que sea útil y accesible para diferentes tipos de usuarios y
necesidades.

Las Cuatro Categorías
=====================

**Tutoriales** (Learning-Oriented)
   Orientados al aprendizaje. Guían al usuario paso a paso a través de un proyecto
   específico para que aprenda haciendo.

**Guías** (Task-Oriented)
   Orientadas a tareas. Muestran cómo resolver problemas específicos del mundo real.

**Explicaciones** (Understanding-Oriented)
   Orientadas a la comprensión. Aclaran y profundizan en temas particulares.

**Referencia** (Information-Oriented)
   Orientadas a la información. Proporcionan descripciones técnicas precisas.

Aplicación en ADT
=================

El proyecto ADT utiliza Diátaxis como framework base para organizar toda su
documentación de traducción:


- **Tutoriales:** Guías paso a paso de traducción
- **Guías:** Procedimientos específicos de traducción
- **Explicaciones:** Fundamentos y principios de traducción
- **Referencia:** Estándares, glosarios y especificaciones
