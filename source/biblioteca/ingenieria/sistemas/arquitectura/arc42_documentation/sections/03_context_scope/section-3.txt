  Contenido: Disponibilidad, costo, seguridad, volatilidad, complejidad

contexto_tip_5.rst
  Título: ¡Restringe el contexto a una visión general, evita demasiados detalles!
  Tema: Nivel de detalle
  Contenido: Visión general vs detalles técnicos

contexto_tip_6.rst
  Título: ¡Simplifica el contexto mediante categorización!
  Tema: Categorización
  Contenido: Agrupar interfaces/sistemas similares

contexto_tip_7.rst
  Título: ¡Si hay muchos sistemas externos, agrégalos por criterios explícitos!
  Tema: Agregación
  Contenido: Criterios de agrupación (datos, casos de uso, tecnología)

contexto_tip_8.rst
  Título: ¡Agrega sistemas vecinos similares con puertos!
  Tema: Puertos UML
  Contenido: Símbolos de puerto para clusters

contexto_tip_9.rst
  Título: ¡Muestra todas las interfaces externas!
  Tema: Completitud
  Contenido: Incluir todos los sistemas externos

contexto_tip_10.rst
  Título: ¡Diferencia el contexto de negocio y técnico!
  Tema: Diferenciación business/technical
  Contenido: Cuándo usar cada uno, ejemplos embebidos y web

contexto_tip_11.rst
  Título: ¡En el contexto de negocio, muestra flujos de datos!
  Tema: Flujos de datos
  Contenido: Qué datos se intercambian

contexto_tip_12.rst
  Título: ¡Muestra influencias externas en el contexto!
  Tema: Influencias externas
  Contenido: Regulaciones, estándares, legacy

contexto_tip_13.rst
  Título: ¡Muestra dependencias transitivas en el contexto!
  Tema: Dependencias indirectas
  Contenido: Cuando son relevantes

contexto_tip_14.rst
  Título: ¡Presta atención a los requisitos de calidad en las interfaces externas!
  Tema: Requisitos de calidad
  Contenido: Performance, seguridad, disponibilidad

contexto_tip_15.rst
  Título: ¡Muestra el contexto técnico si el hardware es central!
  Tema: Hardware
  Contenido: Sistemas embebidos, hardware crítico

contexto_tip_16.rst

  Tema: Protocolos y canales
  Contenido: Tecnologías de comunicación

contexto_tip_17.rst
  Título: ¡Combina el contexto de negocio con información técnica!
  Tema: Combinación
  Contenido: Cuándo combinar ambos contextos

contexto_tip_18.rst
