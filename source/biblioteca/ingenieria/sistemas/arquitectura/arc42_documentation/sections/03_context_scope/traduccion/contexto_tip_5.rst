Tip 3-5: ¡Restringe el contexto a una visión general, evita demasiados detalles!
================================================================================

.. tip::
   **Consejo de Contexto arc42**
   
   Mantén el contexto como una visión general de alto nivel.




Documenta Todas las Interfaces Externas
=======================================

Debes documentar **todas** las **interfaces externas** o **vecinos**, aunque la *categorización* o abstracción es una opción válida.
