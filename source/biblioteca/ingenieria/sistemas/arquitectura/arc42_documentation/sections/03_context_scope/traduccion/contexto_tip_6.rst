Tip 3-6: ¡Simplifica el contexto mediante categorización!
=========================================================

.. tip::
   **Consejo de Contexto arc42**
   
   Mantén el **contexto** pequeño y simple: categoriza **interfaces externas**, sistemas o roles de usuario que tengan fuertes similitudes. Muestra explícitamente que son categorías o abstracciones.




Ver el siguiente ejemplo - donde el contexto contiene solo una única interfaz de "reporte" (una "categoría"), que se desglosa en dos tipos diferentes de reportes en el nivel-1.

.. .. figure:: ../figuras/03-context-abstractions.webp
..       :alt: Dibujo de abstracciones de contexto
..       :align: center
..       :width: 80%
   
..       Categorización de interfaces: "reportes" como categoría con tipos específicos

He visto diagramas de contexto con ¡más de 50 (!) **vecinos** externos!, en cuyo caso la categorización es una manera increíble de reducir el desorden visual y hacer que los diagramas sean comprensibles nuevamente...
