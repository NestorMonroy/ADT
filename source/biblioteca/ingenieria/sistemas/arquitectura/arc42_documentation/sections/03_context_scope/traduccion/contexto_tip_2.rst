Tip 3-2: ¡Muestra el contexto como diagrama!
============================================

.. tip::
   **Consejo de Contexto arc42**
   
   Representa el límite del contexto gráficamente.




En el límite gráfico del contexto, debes mostrar el sistema completo como una **caja negra**, por ejemplo, como un solo componente.

Tienes una variedad de opciones gráficas:

* **Nuestra favorita:** Diagramas de componentes o paquetes UML
* Diagramas de casos de uso UML
* Diagramas arbitrarios de "cajas y líneas"

En cualquier caso, debes colocar tu sistema en el medio y los otros sistemas, roles, usuarios, etc., alrededor de él.
