Observaciones
=============

Este ejemplo muestra un **contexto técnico** donde:

* Se identifican los **canales** vinculados al hardware
* Se usan **estereotipos UML** para especificar tipos de canal
* Se documenta el **mapeo** de E/S lógicas a canales físicos
* Se visualizan los **sistemas adyacentes** y sus conexiones técnicas
* Se usa un **modelo de despliegue** UML
