===============================================================
Tip 3-16: ¡Usa el contexto técnico para describir protocolos o canales!
===============================================================

.. tip::
   **Consejo de Contexto arc42**
   
   El **contexto técnico** es el lugar apropiado para documentar **protocolos**, **canales** y tecnologías de comunicación.

----

Como puedes ver en el tip 3-10 (contexto de negocio y técnico), puedes etiquetar explícitamente **protocolos** (SSH, HTTPS, VPN) o **canales** (bus CAN) dentro del **contexto**.

Sin embargo: Para ahorrar esfuerzo, podrías complementar el **contexto de negocio** con información sobre **protocolos** técnicos (como ftp, https o similar). Ver tip 3-17 (complementar contexto de negocio con información técnica).
