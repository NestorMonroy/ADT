=====================================
Tip 9-8: ¡Use herramientas de ADR!
=====================================

.. meta::
   :layout: post
   :title: Tip 9-8: ¡Use herramientas de ADR!
   :tags: decisión, ADR, herramientas
   :category: decisiones
   :permalink: /tips/9-8/

Existen herramientas que facilitan la gestión de ADRs:

* **adr-tools:** CLI para crear y gestionar ADRs
* **log4brains:** Herramienta web para navegar ADRs
* **ADR Manager:** Plugin para IDEs

Estas herramientas ayudan a:

* Crear ADRs con plantillas consistentes
* Navegar entre ADRs relacionados
* Buscar decisiones
* Generar documentación
