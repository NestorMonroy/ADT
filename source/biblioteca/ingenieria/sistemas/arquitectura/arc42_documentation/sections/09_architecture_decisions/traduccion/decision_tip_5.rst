==============================================
Tip 9-5: ¡Documente alternativas rechazadas!
==============================================

.. meta::
   :layout: post
   :title: Tip 9-5: ¡Documente alternativas rechazadas!
   :tags: decisión, alternativas
   :category: decisiones
   :permalink: /tips/9-5/

Al documentar una decisión, también documente las alternativas que se consideraron y rechazaron.

Para cada alternativa rechazada, documente:

* **Qué era:** Descripción breve
* **Por qué se consideró:** Ventajas potenciales
* **Por qué se rechazó:** Razones específicas
* **Contexto:** Cuándo se evaluó

Esto evita que el equipo reconsidere las mismas alternativas en el futuro.

.. warning::
   Sin documentar alternativas rechazadas, los equipos tienden a revisitar las mismas opciones repetidamente.
