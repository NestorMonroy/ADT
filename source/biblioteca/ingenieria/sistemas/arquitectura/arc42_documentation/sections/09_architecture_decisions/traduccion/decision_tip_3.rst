Tip 9-3: ¡Documente decisiones cercanas al código!
==================================================

Mantenga las decisiones cerca del código que se ve afectado.

Opciones:

* En el repositorio de código
* En archivos Markdown junto al código
* Como comentarios en el código fuente
* En la documentación técnica del módulo

.. important::
   Las decisiones documentadas cerca del código tienen mayor probabilidad de mantenerse actualizadas.
