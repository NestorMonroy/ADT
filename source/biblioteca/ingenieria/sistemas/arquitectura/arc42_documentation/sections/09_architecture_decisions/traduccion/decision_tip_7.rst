============================================

Tip 9-7: ¡Mantenga las decisiones actualizadas!
===============================================

.. meta::
   :layout: post
   :title: Tip 9-7: ¡Mantenga las decisiones actualizadas!
   :tags: decisión, mantenimiento
   :category: decisiones
   :permalink: /tips/9-7/

Las decisiones pueden cambiar con el tiempo.

Actualice el estado de las decisiones:

* **Proposed:** Propuesta pero no aceptada
* **Accepted:** Aceptada e implementada
* **Deprecated:** Obsoleta pero aún en uso
* **Superseded:** Reemplazada por otra decisión

.. important::
   Cuando una decisión es reemplazada, agregue un enlace a la nueva decisión.
