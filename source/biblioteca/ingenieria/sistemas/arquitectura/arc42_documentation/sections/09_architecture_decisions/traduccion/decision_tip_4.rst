=========================================================
Tip 9-4: ¡Mantenga las decisiones bajo control de versiones!
=========================================================

Guarde las decisiones en su sistema de control de versiones (Git, SVN, etc.).

Beneficios:

* **Trazabilidad:** Historial completo de cambios
* **Colaboración:** Revisión por pares de decisiones
* **Búsqueda:** Encontrar decisiones fácilmente
* **Sincronización:** Decisiones alineadas con el código

.. note::
   Use archivos de texto plano (Markdown, AsciiDoc, RST) para mejor diff y merge.
