Tip 7-1: ¡Documenta tu infraestructura técnica (hardware)!
==========================================================

.. tip::
   **Consejo de Vista de Despliegue arc42**
   
   Describe la **infraestructura** técnica (es decir, el **hardware** subyacente) en la cual el sistema se ejecuta.




Describe la **infraestructura** técnica (es decir, el **hardware** subyacente) en la cual el sistema se ejecuta. Eso deberá incluir:

* **Nodos**, es decir, procesadores, **servidores**, clúster... y sus
* Relaciones (canales), es decir, bus, **red** o conexiones inalámbricas,
* Elementos de **hardware** adicionales, es decir, firewall, router, switches, almacenamiento, etc.

Podrías usar ya sea **diagramas de despliegue** UML o gráficos de forma libre, como se muestra debajo:

.. .. figure:: ../figuras/07-infrastructure-with-symbols.png
..       :alt: Gráfico de forma libre para describir infraestructura técnica
..       :align: center
..       :width: 70%
   
..       Diagrama de infraestructura con símbolos (por `UML-diagrams.org <https://www.uml-diagrams.org/examples/web-application-network-diagram-example.html?context=depl-examples>`_)

En caso de que a tus stakeholders les gusten tales íconos o símbolos gráficos: ¡usa un conjunto consistente de tales símbolos con una semántica *definida*!
