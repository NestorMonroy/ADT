Restricciones para HTML Sanity Checker
=======================================

El HTML Sanity Checker debe ser:

* **Independiente de plataforma** y debe ejecutarse en los principales sistemas 
  operativos (Windows™, Linux y Mac-OS™)

* **Integrado** con la herramienta de construcción Gradle

* **Ejecutable** desde la línea de comandos

* **Desarrollado** bajo una licencia open-source liberal
