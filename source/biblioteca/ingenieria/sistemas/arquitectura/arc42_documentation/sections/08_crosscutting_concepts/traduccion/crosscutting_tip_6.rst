El glosario (Sección 12 de arc42) y los modelos de dominio son complementarios:

* **Glosario:** Define términos de negocio y técnicos
* **Modelo de dominio:** Muestra relaciones entre conceptos de negocio

Vincule ambos para crear una documentación coherente:

* Referencie términos del glosario en su modelo de dominio
* Use el modelo de dominio para visualizar conceptos del glosario
* Mantenga la consistencia en la terminología

Esto crea una base sólida para la comprensión compartida del sistema.
