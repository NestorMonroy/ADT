Términos Técnicos
=================

.. glossary::
   :sorted:

   arc42
      Framework de documentación de arquitectura de software. Proporciona una 
      plantilla estandarizada para documentar decisiones arquitectónicas.

   AsciiDoc
      Formato de texto plano para escribir notas, documentación, artículos, 
      libros y más. Similar a Markdown pero con más características.

   Calibración automática
      Proceso por el cual un sistema de medición se ajusta automáticamente 
      usando referencias externas (como GPS) para garantizar precisión.

   Correctness (Corrección)
      Atributo de calidad que indica que el sistema produce resultados exactos 
      y conformes a las especificaciones.

   Driving forces (Factores determinantes)
      En arquitectura de software, los factores que impulsan y moldean las 
      decisiones arquitectónicas. Incluyen requisitos funcionales clave, 
      atributos de calidad críticos, restricciones técnicas o de negocio, 
      y cualquier factor que IMPULSE decisiones arquitectónicas. 
      
      **Nota de traducción:** NO traducir literalmente como "fuerzas impulsoras". 
      El término arquitectónico correcto es "factores determinantes" o "impulsores".

   Ease of use (Facilidad de uso)
      Atributo de calidad que mide qué tan fácil es para los usuarios 
      interactuar con el sistema.

   Enterprise Architect
      Herramienta de modelado UML y diseño de software. Marca registrada (TM).

   Flexibility (Flexibilidad)
      Capacidad del sistema para adaptarse a diferentes contextos, 
      configuraciones o requisitos cambiantes.

   Gradle
      Sistema de automatización de builds de código abierto. Usado comúnmente 
      en proyectos Java y Android.

   HTML Sanity Checker (HtmlSC)
      Sistema que verifica errores semánticos en archivos HTML, como enlaces 
      rotos e imágenes faltantes.

   Markdown
      Lenguaje de marcado ligero para crear texto formateado usando un editor 
      de texto plano. Alternativa más simple a HTML.

   MeasuringUnit
      Unidad de medición en el sistema TPU que contiene todos los componentes 
      sujetos a aprobación legal.

   Performance (Rendimiento)
      Atributo de calidad que mide la velocidad, capacidad de respuesta y 
      eficiencia del sistema.

   Quality goals (Atributos de calidad objetivo)
      Los tres a cinco atributos de calidad principales que la arquitectura 
      debe satisfacer, según las prioridades de los stakeholders clave. Son 
      atributos MEDIBLES Y ESPECÍFICOS de la ARQUITECTURA, no del proyecto.
      
      Ejemplos:
      - Performance: < 2 segundos response time
      - Availability: 99.9% uptime
      - Maintainability: < 4 horas para hotfix
      
        **Nota de traducción:** NO traducir simplemente como "objetivos de calidad" 
        (demasiado literal). Usar "atributos de calidad objetivo" o preservar el 
        término técnico "quality goals".

   Robustness (Robustez)
      Capacidad del sistema para funcionar correctamente bajo condiciones 
      adversas o inesperadas.

   Safety (Seguridad)
      Atributo de calidad que garantiza que el sistema no cause daño, 
      corrupción de datos o efectos no deseados.

   Stakeholder
      Persona, rol u organización que tiene interés en el sistema y su 
      arquitectura. Término técnico internacional que NO se traduce. También 
      conocido en español como "parte interesada" pero en arquitectura de 
      software se preserva el término en inglés por ser estándar internacional 
      en gestión de proyectos y arquitectura de software.

   Traffic Pursuit Unit (TPU)
      Sistema de medición de velocidad con grabación de video instalado en 
      vehículos policiales para documentar infracciones de tráfico.

   Use case diagram (Diagrama de casos de uso)
      Diagrama UML que muestra las interacciones entre actores (usuarios) y 
      el sistema para lograr objetivos específicos.

Términos Específicos del Dominio
================================

.. glossary::

   Pursuit (Persecución)
      En el contexto de TPU, acción de seguir un vehículo a alta velocidad 
      para documentar infracciones de tráfico.

   Semantic error (Error semántico)
      Error en HTML que no impide el renderizado pero afecta la corrección o 
      funcionalidad (ej: enlace roto).




Notas de Traducción
===================

Decisiones de Traducción
========================

1. **"Driving forces"**: Traducido como "fuerzas impulsoras" en lugar de 
   "fuerzas conductoras" para mantener el sentido de motivación/impulso.

2. **"HTML Sanity Checker"**: Mantenido en inglés como nombre propio del 
   sistema, con abreviatura HtmlSC.

3. **"Traffic Pursuit Unit"**: Traducido como "Unidad de Persecución de 
   Tráfico" con la abreviatura TPU mantenida en inglés.

4. **Atributos de calidad**: Términos como "Correctness", "Robustness", 
   "Safety" traducidos pero con referencia al término original inglés para 
   claridad.

5. **"MeasuringUnit"**: Mantenido en inglés al ser un nombre específico de 
   componente del sistema TPU.
