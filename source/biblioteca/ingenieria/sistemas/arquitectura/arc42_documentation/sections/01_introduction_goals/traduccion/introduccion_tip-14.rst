Recomendación
=============

Con su representación jerárquica (ver el diagrama a continuación), el estándar 
ISO 25010 proporciona una buena checklist para "temas" de calidad de alto nivel.

Como alternativa más práctica, considera el subproyecto de arc42 "ejemplos de 
requisitos de calidad" (ver :ref:`introduccion-tip-15`) que contiene más de 60 
ejemplos del mundo real de requisitos de calidad.

.. figure:: /biblioteca/ingenieria/sistemas/arquitectura/arc42_documentation/sections/01_introduction_goals/figuras/01-ISO-25010-EN.webp
   :alt: Calidad de Producto de Software - estándar ISO 25010 - representación jerárquica
   :align: center
   :width: 80%

   Calidad de Producto de Software - estándar ISO 25010

Algunos "temas de calidad" comunes son:

- Disponibilidad (availability)
- Modificabilidad (modifiability)
- Mantenibilidad (maintainability)
- Confiabilidad / Robustez (reliability / robustness)
- Rendimiento / eficiencia en tiempo de ejecución (performance / runtime efficiency)
- Seguridad (security)
- Safety (seguridad funcional)
- Usabilidad (usability)
- Testeabilidad (testability)
