===================================================================
Consejo 1-7: ¡Usa diagramas BPMN!
===================================================================

:Subtítulo: Para describir requisitos funcionales
:Tema: Business Process Model Notation
:Categoría: Requisitos
:Audiencia: Arquitectos, Stakeholders de negocio

----

Recomendación
=============

En caso de que tus stakeholders perciban los diagramas de actividad como 
demasiado técnicos, puedes usar diagramas BPMN.

La Notación de Modelado de Procesos de Negocio (Business Process Model Notation) 
se dirige explícitamente a stakeholders de negocio y, por lo tanto, puede verse 
como una alternativa a los diagramas de actividad para describir procesos de 
negocio o técnicos.
