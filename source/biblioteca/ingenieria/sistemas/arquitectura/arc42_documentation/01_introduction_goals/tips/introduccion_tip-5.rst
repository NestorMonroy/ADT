Consejo 1-5: ¡Asegúrate de poder referenciar requisitos!
========================================================

.. meta::
   :layout: post
   :title: Consejo 1-5: ¡Asegúrate de poder referenciar requisitos existentes!
   :tags: requirement thorough
   :category: requirements
   :permalink: /tips/1-5/

:Tema: Referencias a requisitos
:Categoría: Requisitos
:Audiencia: Arquitectos, Desarrolladores




Recomendación
=============

En caso de que estés referenciando requisitos existentes en la documentación de 
arquitectura, por ejemplo para justificar una decisión de diseño, necesitas 
asegurar que estos requisitos puedan ser identificados de manera única, mediante 
una clave corta o algo similar.

Opciones
========

- A veces puedes tomar esos IDs de la documentación de requisitos.
- Si tus requisitos están gestionados por una herramienta (por ejemplo, un issue 
  tracker), puedes usar esos IDs - con algunas herramientas incluso tienes URLs 
  estables.
