====================================================================

Tip 9-1: ¡Documente solo decisiones arquitectónicamente relevantes!
===================================================================

.. meta::
   :layout: post
   :title: Tip 9-1: ¡Documente solo decisiones arquitectónicamente relevantes!
   :tags: decisión, calidad, stakeholder, lean
   :category: decisiones
   :permalink: /tips/9-1/

.. epigraph::

   (Documente) decisiones "arquitectónicamente significativas": aquellas que afectan la estructura, características no funcionales, dependencias, interfaces o técnicas de construcción.
   
   -- `Michael Nygard <https://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions>`_

No documente cada pequeña decisión de desarrollo, sino concéntrese en las siguientes:

* críticas o importantes para el sistema
* que influyen en atributos de calidad importantes
* no convencionales ("fuera del camino trillado")
* riesgosas
* con consecuencias costosas
* con efectos duraderos
* que afectan a:
  
  * un gran número de stakeholders
  * stakeholders muy especiales o importantes
  
* que tomaron mucho tiempo o esfuerzo para decidir
* sorprendentes
