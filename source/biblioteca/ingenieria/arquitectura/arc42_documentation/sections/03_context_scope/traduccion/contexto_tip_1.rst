Tip 3-1: ¡Demarca explícitamente tu sistema de su entorno!
==========================================================

.. tip::
   **Consejo de Contexto arc42**
   
   Define "qué está dentro" de tu sistema y qué está afuera.




Debes demarcar tu sistema de otros sistemas IT para mostrar cómo encaja en el entorno IT existente, qué **interfaces externas** se ofrecen o consumen, y qué usuarios o roles están usando el sistema.

De esta manera muestras el **alcance** de tu sistema: cuáles son las responsabilidades de tu sistema y cuáles son las responsabilidades de sus **sistemas vecinos**.

Encuentras un ejemplo en el diagrama a continuación: Muestra el contexto de una tienda web que delega el manejo de pagos a un proveedor externo (removiendo esta responsabilidad del alcance de la tienda web).
