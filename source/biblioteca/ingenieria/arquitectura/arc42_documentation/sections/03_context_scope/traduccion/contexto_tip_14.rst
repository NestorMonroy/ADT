Tip 3-14: ¡Presta atención a los requisitos de calidad en las interfaces externas!
==================================================================================

.. tip::
   **Consejo de Contexto arc42**
   
   Las **interfaces externas** pueden tener requisitos de calidad especiales.




Pueden aplicar requisitos de calidad especiales a las **interfaces** de tu propio sistema y tal vez también a tus sistemas externos, por ejemplo, requisitos de seguridad, throughput o disponibilidad. Estos llamados "niveles de servicio" necesitan ser tratados con cuidado, porque pueden tener altos gastos y riesgos de implementación y operación.

Podrías denotar requisitos o metas de calidad especiales en tu diagrama de **contexto**.

En el ejemplo siguiente, encuentras dos marcadores en **interfaces externas** que indican que las interfaces correspondientes influyen en estas metas de calidad.
