Apéndices
=========

Metodología de Cálculo
-----------------------

**Progreso Global:**

.. code-block:: python

 progreso_global = (
 sum(libro.paginas_traducidas for libro in libros) /
 sum(libro.total_paginas for libro in libros)
 ) * 100

**Velocidad de Traducción:**

.. code-block:: python

 velocidad_diaria = (
 total_paginas_traducidas /
 dias_laborales_transcurridos
 )

**Estimación de Finalización:**

.. code-block:: python

 dias_restantes = (
 paginas_pendientes /
 velocidad_promedio_diaria
 )
