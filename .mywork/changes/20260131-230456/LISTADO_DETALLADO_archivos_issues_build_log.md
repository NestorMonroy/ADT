## 🔧 GUÍA DE SOLUCIONES POR TIPO DE ISSUE

### CRITICAL

#### "Unexpected section title"
**Problema**: Sphinx encuentra un título en un contexto inesperado.

**Causas comunes**:
1. Título dentro de `.. code-block::` sin indentar correctamente
2. Título dentro de lista sin indentación adecuada
3. Underline con longitud incorrecta

**Solución**:
```rst
# ❌ INCORRECTO
.. code-block:: rst

 Título         ← Solo 1 espacio
 ======

# ✅ CORRECTO
.. code-block:: rst

   Título       ← 3+ espacios
   ======
```

#### "Missing matching underline for section title overline"
**Problema**: El underline no coincide con el título.

**Solución**:
```rst
# ❌ INCORRECTO
Título         ← 6 caracteres
========       ← 8 signos (no coincide)

# ✅ CORRECTO
Título         ← 6 caracteres
======         ← 6 signos (coincide)
```

---

### ERROR

#### "Unexpected indentation" / "Unexpected unindent"
**Problema**: Indentación inconsistente.

**Solución**:
- Usar SOLO espacios (no tabs)
- Mantener niveles consistentes (múltiplos de 3 o 4)
- Verificar que directivas tengan contenido indentado

```rst
# ✅ CORRECTO
.. note::
   
   Este contenido está indentado correctamente.
   
   Segunda línea también.
```

#### "Malformed table"
**Problema**: Tabla con formato incorrecto.

**Solución**:
```rst
# ✅ CORRECTO para list-table
.. list-table::
   :header-rows: 1

   * - Columna 1
     - Columna 2
   * - Dato 1
     - Dato 2
```

#### "Could not lex literal_block as 'X'"
**Problema**: Lexer no soportado o nombre incorrecto.

**Solución**:
```rst
# ❌ INCORRECTO
.. code-block:: javascript-es6

# ✅ CORRECTO
.. code-block:: javascript

# Lexers comunes soportados:
# - python, bash, rst, text
# - javascript, java, cpp, c
# - sql, yaml, json, xml
```

### WARNING

#### "document isn't included in any toctree"
**Problema**: Archivo .rst existe pero no está referenciado.

**Solución**:
- Agregar a un `.. toctree::` en archivo padre
- O usar `:orphan:` al inicio si es intencional

```rst
# En archivo padre
.. toctree::
   :maxdepth: 2

   archivo_hijo
```

#### "Explicit markup ends without a blank line"
**Problema**: Falta línea en blanco después de directiva.

**Solución**:
```rst
# ❌ INCORRECTO
.. note::
   Contenido
Siguiente párrafo

# ✅ CORRECTO
.. note::
   Contenido

Siguiente párrafo    ← Línea en blanco antes
```

#### "duplicate label"
**Problema**: Dos secciones con el mismo nombre.

**Solución**:
```rst
# ✅ CORRECTO - Usar etiquetas únicas
.. _seccion-introduccion-capitulo1:

Introducción
============

...

.. _seccion-introduccion-capitulo2:

Introducción         ← Mismo título, etiqueta diferente
============
```
