# Work-log: Descarga del repositorio Sphinx

Fecha: 2026-01-29

## Objetivo

Actualizar la estrategia de infraestructura descargando el repositorio
oficial de Sphinx dentro de `tools/_downloads` para futuras referencias
(local mirror o inspeccion de inventarios).

## Comandos ejecutados

- `git clone --no-checkout https://github.com/sphinx-doc/sphinx tools/_downloads/sphinx`
- `curl -L https://github.com/sphinx-doc/sphinx/archive/refs/heads/master.tar.gz -o tools/_downloads/sphinx-master.tar.gz`
- `tar -xzf tools/_downloads/sphinx-master.tar.gz -C tools/_downloads`

## Resultado

- El repositorio se clono en `tools/_downloads/sphinx`.
- Se uso `--no-checkout` porque el checkout completo fallo por errores
  de codificacion (`failed to encode ... from UTF-8 to iso-8859`).
- Se descargo un tarball con el codigo fuente en
  `tools/_downloads/sphinx-master` para evitar conversiones de checkout.

## Siguiente accion

- Si se requiere el checkout de archivos, ajustar configuracion de git
  para soportar los archivos `wrongenc.inc` y reintentar el checkout.
- Mantener el tarball como alternativa cuando solo se necesita el codigo.
